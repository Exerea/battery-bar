# BatteryBar

Windows タスクバー（通知領域の左）に、**選んだワイヤレス機器のうち残量が少なくなったものだけ**を横一列で表示する軽量常駐ツールです。

普段はタスクバーを邪魔せず、充電が必要なときだけ静かに知らせます。

## 特徴
- **残量が減った機器だけ表示（既定）**: 充電が十分なときはタスクバー横一列を自動で隠し、右下のシステムトレイに小さなアイコンだけ残します。
- **すべてメニューから設定**: 設定ファイルを直接編集する必要はありません。見守る機器の ON/OFF、表示する残量の目安（全体 15〜50% / 機器ごと）、短い機器名の表示、充電中の非表示、Windows 起動時の自動起動をすべてメニューから切り替えられます。
- **ちらつきにくい安定表示**: ワイヤレス機器の一時的なスリープによる点滅を防ぎ、フルスクリーン（ゲーム・動画）中は自動で隠れます。Explorer 再起動・スリープ復帰・USB / Bluetooth 抜き差しにも自動で追従します。
- **軽量・単一ファイル**: Rust + Win32 API のみ（約 420 KB / アイドル時 CPU 0%・メモリ数 MB）。二重起動防止あり。
- **完全オフライン・管理者権限不要**: ネットワーク通信・自動更新・情報送信は一切ありません。外部ツールの同梱や他プロセスへの注入も行いません。

## はじめ方
1. [Releases](https://github.com/Exerea/battery-bar/releases) から `battery-bar.exe` をダウンロードしてダブルクリックで起動します（インストール不要）。
2. 初回起動時は接続中の機器を自動で見守り対象にし、検出一覧のメニューを開きます。
3. 右下のシステムトレイ（または `^` の中）にあるバッテリーアイコンをクリックすると、いつでも設定を変更できます。
   - 起動中に `battery-bar.exe` をもう一度開いても二重起動はされず、既存プロセスのメニューが開きます。
   - 見た目をすぐ確認したい場合は、メニューの「選んだ機器をすべて表示」を選ぶと現在の残量を常時表示できます。

> **Note**: 未署名の実行ファイルのため、初回起動時に Windows SmartScreen の確認画面が出ることがあります。気になる場合は、下の「ビルド方法」からソースコードを直接ビルドできます。

## 使わなくなったときの消し方（アンインストール）
PC に設定や自動起動を残さず、2 ステップで完全に削除できます。

1. システムトレイのバッテリーアイコンをクリックし、**「自動起動と設定を消して終了...」** を選んで確認ダイアログで **「はい」** を押します。
   - Windows の自動起動設定と保存データ（`%APPDATA%\BatteryBar`）をすべて削除して終了します。
2. 終了後、ダウンロードした `battery-bar.exe` をゴミ箱へ移します。

コマンドラインから同じ後片付けを行うこともできます。

```powershell
.\battery-bar.exe --uninstall
```

## 対応するバッテリー取得元
- **Bluetooth 機器全般**: Windows の「Bluetooth とデバイス」で残量を取得できる BLE / Classic Bluetooth 機器（キーボード・マウス・イヤホン・ヘッドホン等）
- **Logitech ワイヤレス機器**: HID++ 2.0 対応の LIGHTSPEED / Bolt / Unifying / G ヘッドセット（読み取り専用の独自 Software ID で既存ユーティリティと共存）
- **標準 HID バッテリー対応機器**: HID Battery Usage (`0x06:0x20` / `0x85:0x65`) 対応の周辺機器（ペンタブレット等の Digitizer は誤動作防止のため除外）
- **Xbox / XInput コントローラー**: `xinput1_4.dll` 経由で無線コントローラーを検出
- **Windows スマートフォン連携（Phone Link）**: ローカル状態ファイルの読み取り専用パース（iPhone / Android、日本語・英語対応）
- **PC 本体 / UPS バッテリー**: ノート PC や UPS 接続時のみ自動検出

## コマンドラインオプション（上級者向け）
- `battery-bar.exe --list`: 検出した機器と残量を一覧表示
- `battery-bar.exe --json`: 検出結果を JSON で出力
- `battery-bar.exe --always`: 選んだ機器を常時表示モードで起動
- `battery-bar.exe --uninstall`: 自動起動設定と保存データを削除して終了

## ビルド方法
Windows + Rust (MSVC ツールチェイン) が必要です。

```powershell
powershell -ExecutionPolicy Bypass -File .\build-release.ps1
```

`target\release\battery-bar.exe` にローカルパス情報を含まないクリーンなリリースバイナリが生成されます。
